# Security Policy

## Supported Versions

This is a static site with no backend. The `main` branch is the only supported
version and is what gets deployed to GitHub Pages.

## Reporting a Vulnerability

If you discover a security issue (for example, an XSS vector in the Markdown
reader), please **do not open a public issue**. Instead, email the maintainer:

**dawidpolakowski@gmail.com**

Please include:

- A description of the issue and its impact
- Steps to reproduce
- Any suggested fix, if you have one

You can expect an acknowledgement within a few days. Thank you for helping keep
the project safe.
